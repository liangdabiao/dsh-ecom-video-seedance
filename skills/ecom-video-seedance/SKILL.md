# Ecom Video → Seedance Prompt（agent 原生 · 零密钥）

看懂一条带货视频，把它翻译成可复刻的 Seedance 提示词。

**分工（先记住这条）：**

- **脚本只做确定性的事**：ffprobe 元信息、1fps 抽帧、场景切换检测、镜头切分、关键帧清单、
  字数与字段硬校验、md/HTML 渲染。不联网、不调模型、不需要任何 API key。
- **看帧拆解 + 提示词编导 = 你自己做**。你本身就是视觉模型：用 `read_image` 直接读关键帧。
  不要去找外部视觉 API，不要装 `openai`，不要说"缺 API key"——这条链路上没有密钥这回事。

## 为什么不让脚本调模型

1. **帧进你自己的上下文，能跨镜比对**：A 镜那只手和 C 镜那只手是不是同一只、发丝在三个镜头里
   卷度有没有变、光位有没有漂——外部视觉 API 每次只看一小段，看不到前后关系，只能猜。
2. **零密钥零成本**：不依赖 `DEEPSEEK_API_KEY`、不消耗额度、不怕 401 和限流（这两种失败会让整条
   流水线卡死在第一步，实测过）。
3. **失败点少**：脚本挂了是脚本问题；内容不对就直接改 JSON 重跑校验，不烧积分、不重跑整条链。

## 四步工作流

### 第 0 步：把技能目录复制到工作区

**你的 bash 沙箱读不到插件安装目录**，需要读 references/ 或跑脚本时，先把整个技能目录复制到当前工作区：

```bash
cp -r "<本技能目录>" ./seedance-skill
```

之后一律在工作区副本 `./seedance-skill/` 里操作；产出文件写到当前工作区，不要往插件目录写。

### 第 1 步：感知准备（脚本，几秒，不调模型）

```bash
python scripts/analyze.py "<视频路径>"
```

它做四件事，产出 `.cache/<sha16>/frames/` 和 `.cache/<sha16>/manifest.json`：

1. ffprobe 元信息（时长 / 分辨率 / 画面比例 / 有没有音轨）
2. 1fps 抽帧（>120s 自动降 0.5fps）
3. ffmpeg 场景切换检测（scene>0.25）→ 剪辑点
4. 按剪辑点切镜头（合并 <0.8s 碎片），每镜挑首 / 1/4 / 中 / 3/4 / 尾关键帧，打印**绝对路径清单**

常用参数：`--min-shot 0.8`｜`--fps 2`（动作快的片子）｜`--force` 重建｜`--clean` 清缓存｜`--json` 只要 JSON。
它会打印「下一步」，照做即可。

### 第 2 步：你看帧，写两张 JSON（这是主活）

**先通读一遍全片再动笔**：按 manifest 把每镜的关键帧都读了，脑子里先有整条片子的动作流，
再决定镜头卡怎么写、提示词怎么排。批读技巧：**一个 tool block 里并发读 6-8 张**，别一张一张来。

用 `read_image` 读帧后，写两个文件：

| 文件 | 作用 | 位置 |
|---|---|---|
| `storyboard.json` | 镜头拆解卡（S-A-C-S-C 逐镜 + 全片带货判断） | `.cache/<sha16>/storyboard.json` |
| `payload_<style>.json` | 提示词包（每镜提示词 + 完整版 + 负面词 + @参考图 + 差异说明 + 升级建议） | 当前工作区 |

字段定义见 `references/storyboard-schema.md`，**必须逐字段对齐**——校验器按它卡。
想省事可以先 `python scripts/replicate.py "<视频>" --scaffold --style faithful` 生成骨架再填。

写镜头卡的要求：

- **人物四层**：身份标签 → 外貌特征 → 服装（颜色具体）→ 气质表情（用物理描述："嘴角微微上扬"而不是"开心"）
- **动作时序 3-5 步**：写慢、写连续、写过程（"抬起→触碰→停留→放下→回弹"），每步带时间感
- **产品写"材质+纹理"双重描述**，有可见文字/LOGO 就如实记录（后面当不可控元素处理）
- **画面内文字/水印如实写进 `onscreen_text`**，不要美化也不要臆造

写提示词包的要求见下面「写稿硬规则」。

### 第 3 步：校验 + 渲染（脚本，硬校验不过不放行）

```bash
python scripts/replicate.py "<视频>" --payload payload_faithful.json --style faithful --duration 15
```

- 会先跑**分镜表校验**和**提示词包校验**：字段齐不齐、每镜是否 ≤200 字、完整版是否 ≤800 字、
  镜头 id 和分镜表对不对得上、@参考图有没有写"怎么准备"。不过就 `exit 1` 并列出**全部**问题。
- 通过后渲染 `<视频名>_<风格>_提示词.md` 和 `.html`（HTML 自包含，每镜提示词旁配 3 张原片关键帧 + 字数标签）。
- `--check` 只校验不渲染；`--shot A,B` 只渲染指定镜头；`--style organic|paid` 换风格。

**校验没过就改 JSON 重跑，不要绕过校验、也不要手动改渲染产物。**

### 第 4 步：交付 + 存分镜表

1. 把分镜表存进插件：`seedance_storyboard action=save`，`scenes` 每镜
   `{shot 镜头一句话, narration 口播, visual 画面要点, duration 秒}`，`style` 填中文风格名，`note` 写"初版"。
2. 给用户：**HTML 预览路径** + **完整版提示词整段**（可直接粘即梦）+ **@参考图清单**怎么准备。
3. 明确说明哪些元素**不可控**（品牌 LOGO / 水印 / 版权外观 / 密集小图背景 / 多只手），
   按 `fidelity_notes` 的处理办法交代清楚：留后期贴、去 logo 替代、降级为单只手等。
4. 口播要说清是**推断**：本技能只读画面、不分析音轨。

## 写稿硬规则（校验器会逐条卡）

- **每镜 ≤200 字**（建议 120-180）；**完整版 ≤800 字**。按字符数算，含标点。
- **五要素齐全**：主体 / 动作 / 场景 / 镜头（景别×视角×景深×运镜）/ 色彩情绪。缺一项就是让模型自由发挥。
- **一条视频一种主运镜**；5 秒内不切光影风格。
- **动作写慢写连续**：用"缓慢/轻柔/连贯/自然/流畅"，禁用剧烈动作、多人复杂交互。
- **约束尾必带**：人脸五官对称无脸崩、人体结构正常、同一角色服装发型一致、产品无穿模、
  颜色无偏色、无抖动无模糊无闪烁。
- **@占位不发明**：`@产品参考图1`、`@人物参考图1`、`@道具参考图1`、`@场景参考图1（可选）`，
  和 `reference_assets` 里的 `name` 一一对应。
- **单镜单重点**，剔除"好看/高级/有质感"这类模糊词（等于没写）。

编导细节全部在 `references/seedance-knowledge.md`（S-A-C-S-C、字数法则、自然流 vs 付费流五维表、
品类优化词、负面词模板、避坑清单）——**改风格前先读它**。

## 三种风格（`--style`）

- `faithful` 忠实复刻：切分、时长、构图、光位、动作时序照原片，只换不可控元素。
- `organic` 自然流：真实场景、自然光、中景跟拍、痛点/种草叙事，常补促单镜头。
- `paid` 付费流：黄金 3 秒奇观钩子、极致特写、硬光侧逆光、快节奏、结尾行动号召。

## 常见坑

1. **别只读一帧就写**：单帧看不出动作方向、卷度、光位漂移，至少读 3 张（首/中/尾）。
2. **别把镜头切的边界帧写重**：镜头区间是左闭右开，边界帧属于后一镜。
3. **别跳过 payload**：只交 storyboard 等于只交了半成品，用户要的是能粘进即梦的整段提示词。
4. **别把不可控元素写进正向提示词**：品牌水印、iPhone 摄像头排列、照片墙具体小图，
   写进正向就是逼模型生成乱码。按差异说明处理。
5. **人数/手数收敛**：多手同框是 Seedance 高翻车区，每镜只留一只画外手；超长指甲、复杂首饰同理。
6. **时长换算**：原片 10s 出 15s 成片时，时间锚点等比放大；`--duration` 只影响锚点与校验，不影响已写文案。

## 环境要求

- `ffmpeg` / `ffprobe` 在 PATH（脚本会自己检查并给安装提示）
- Python 3.8+，**只用标准库**（不需要 `pip install` 任何东西）
- 不需要 API key、不需要联网

## 缓存与重跑

- 单视频感知结果永久缓存：`.cache/<sha16>/`（`manifest.json` + `frames/` + 你写的 `storyboard.json`）。
- 视频改了 sha 变，会自动另建一份，不会串。
- 只重出某一镜：改 `payload_<style>.json` 里那一镜的 `prompt`，跑 `--shot B` 重渲染即可。
- 换风格：复制一份 `payload_<新风格>.json` 改文案，`--style organic` 重跑。

## 与旧版的区别（别按旧文档操作）

旧版靠 `analyze.py`/`replicate.py` 调 DeepSeek 视觉 API（要 `openai` 包 + 密钥）。**现在没有 `ds_client.py`，
脚本不碰网络**。任何"需要 DEEPSEEK_API_KEY"的说法都是过时信息；你要是发现有残留的 API 调用，
那是 bug，按「脚本只做确定性的事」这条原则改掉。
